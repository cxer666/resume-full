# 简历填写助手 MVP

这是一个电脑端半自动简历填写助手，目标是在两天内做出可用版本。

## 已实现功能

- 本地设置界面，标题为“简历填写助手”
- 读入 `txt / docx / pdf` 简历
- 自动提取并存储基础信息
- 内容编辑，自动保存到本地 JSON
- 版本分类存储：可新建“通用版 / 游戏QA版 / 测试岗版”等版本
- 个人简历网页生成，支持照片、视频、项目说明
- Chrome / Edge 扩展：招聘网页右下角浮动按钮
- 一键填写：只填空字段，不覆盖已有内容
- 检查对比：发现疑似错填项后，由用户确认替换
- 测试招聘表单：`http://127.0.0.1:17888/test_form.html`

## 快速启动

1. 双击 `打开简历填写助手.bat`
2. 浏览器自动打开 `http://127.0.0.1:17888/`
3. 在设置页导入或编辑简历
4. 安装浏览器扩展
5. 打开招聘网站，使用右下角“填写 / 检查”

## 安装浏览器扩展

Chrome / Edge：

1. 打开扩展管理页：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
2. 打开“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本工程里的 `extension` 文件夹
5. 保持本地服务运行

## 重要边界

- 第一版不会自动提交简历。
- 第一版不会绕过验证码、登录验证、风控。
- 第一版不是所有招聘网站都能完美适配。
- 富文本、iframe、Shadow DOM、动态选择器可能需要手动补充。
- PDF 解析依赖 PDF 文本层；扫描件 PDF 需要 OCR，第一版不做 OCR。
- 检查功能是“辅助判断”，不应无脑批量替换。

## 数据位置

- 简历数据：`data/resume_store.json`
- 上传文件：`uploads/`
- 生成网站：`generated_site/index.html`

所有数据默认保存在本地，不上传云端。

## 推荐使用流程

1. 先导入一份最完整的简历。
2. 在内容编辑里检查姓名、手机、邮箱、学校、项目、实习是否正确。
3. 新建“游戏QA版”或“测试岗版”，针对岗位修改项目和自我评价。
4. 打开招聘网站后先点“扫描”，确认能识别字段。
5. 点“填写”，再人工检查。
6. 若招聘网站已有自动填充内容，点“检查”，只替换明显错误项。
