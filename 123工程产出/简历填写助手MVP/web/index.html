浏览器扩展使用

当前关闭：招聘网页不会显示悬浮窗
  1. 打开 Chrome / Edge 的扩展管理页，启用开发者模式。
  2. 选择“加载已解压的扩展程序”，选择本工程的 extension 文件夹。
  3. 加载扩展后，先在这里手动开启悬浮窗；开启后当前页面、已刷新网页和新打开网页都会自动显示可拖动悬浮窗。需要关闭时，再回到这里点击关闭。
