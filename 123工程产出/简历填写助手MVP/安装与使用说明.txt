简历填写助手 MVP 安装与使用说明

一、启动本地设置页

1. 双击“打开简历填写助手.bat”
2. 浏览器会打开：http://127.0.0.1:17888/
3. 不要关闭黑色命令行窗口，关闭后扩展无法读取本地简历数据。

如果提示没有 Python，请安装：
winget install Python.Python.3.12

二、导入简历

1. 在“读入简历”区域选择 txt / docx / pdf 文件。
2. 点击“读入简历”。
3. 导入后到“内容编辑”里人工检查一次。
4. 修改会自动保存。

三、安装 Chrome / Edge 扩展

Chrome:
1. 地址栏输入 chrome://extensions/
2. 打开右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本工程的 extension 文件夹

Edge:
1. 地址栏输入 edge://extensions/
2. 打开“开发人员模式”
3. 点击“加载解压缩的扩展”
4. 选择本工程的 extension 文件夹

四、使用自动填写

1. 保持本地服务运行。
2. 打开招聘网站表单页面。
3. 右下角会出现“简历助手”浮动按钮。
4. 点击“扫描”查看识别情况。
5. 点击“填写”自动填入空字段。
6. 点击“检查”对比已有内容和本地简历库，发现错填项后手动确认替换。

五、生成个人简历网页

1. 可上传照片和视频。
2. 点击“生成个人简历网页”。
3. 系统会生成 generated_site/index.html，并自动打开本地网页。

六、第一版限制

1. 不自动提交。
2. 不绕过验证码。
3. 不保证所有招聘网站字段都能精准识别。
4. PDF 扫描件无法准确读取，需要手动复制文本。
5. 若网站使用复杂 iframe / Shadow DOM，可能只能部分填写。
