## 简历填写助手

一个本地运行的简历填写辅助工具，用于读取、管理多版本简历内容，并配合浏览器扩展在招聘网站中进行半自动填写、检查和反向提取。

## 功能

- 读取 `txt / docx / pdf` 格式简历
- 本地存储多版本简历，例如：通用版、策划版、测试版、开发版
- 支持项目经历、实习经历、获奖信息、AI 能力、语言水平等分段编辑
- 支持浏览器悬浮窗，一键填写招聘网站表单
- 支持检查已填写内容并替换错误项
- 支持从招聘网站反向提取已填写内容，新建存档
- 支持生成个人简历网页
- 所有简历数据默认保存在本地，不上传服务器

## 快速启动

1. 双击 `打开简历填写助手.bat`
2. 浏览器自动打开 `http://127.0.0.1:17888/`
3. 在设置页导入或编辑简历
4. 安装浏览器扩展
5. 打开招聘网站，使用右下角“填写 / 检查”

## 安装浏览器扩展

Chrome / Edge：

1. 打开扩展管理页：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
2. 打开“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本工程里的 `extension` 文件夹
5. 保持本地服务运行

## 重要边界

- 第一版不会自动提交简历。
- 第一版不会绕过验证码、登录验证、风控。
- 第一版不是所有招聘网站都能完美适配。
- 富文本、iframe、Shadow DOM、动态选择器可能需要手动补充。
- PDF 解析依赖 PDF 文本层；扫描件 PDF 需要 OCR，第一版不做 OCR。
- 检查功能是“辅助判断”，不应无脑批量替换。

## 数据位置

- 简历数据：`data/resume_store.json`
- 上传文件：`uploads/`
- 生成网站：`generated_site/index.html`

所有数据默认保存在本地，不上传云端。

## 推荐使用流程

1. 先导入一份最完整的简历。
2. 在内容编辑里检查姓名、手机、邮箱、学校、项目、实习是否正确。
3. 新建“游戏QA版”或“测试岗版”，针对岗位修改项目和自我评价。
4. 打开招聘网站后先点“扫描”，确认能识别字段。
5. 点“填写”，再人工检查。
6. 若招聘网站已有自动填充内容，点“检查”，只替换明显错误项。
